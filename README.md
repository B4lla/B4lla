## Selected work

### Frame — Private

**TypeScript · React · Next.js · PostgreSQL · Cloud infrastructure**

A SaaS visual editor for building responsive web interfaces and exporting them as production-ready projects.

It is currently my main development project and combines frontend architecture, backend systems, infrastructure and product development.

---

### [SecureNotes](https://github.com/B4lla/SecureNotes)

**Vue · Node.js · PostgreSQL · Cryptography**

Self-hosted personal notes application designed around privacy.

Notes are encrypted client-side before reaching the server, using an architecture focused on end-to-end encryption and minimizing trust in backend infrastructure.

---

### [Swords & Fireballs](https://github.com/B4lla/Swords-Fireballs)

**JavaScript · Tailwind CSS · jQuery**

Turn-based strategy game with multiple troop classes, resource management, persistent game state and asynchronous systems.

The project uses modular ES6 architecture, centralized state management, event delegation and reusable game logic.

---

### [FFE Management](https://github.com/B4lla/ffe-managment)

**PHP · Laravel**

Management application designed to organize internship documentation and workflows for high-school students.

---

### [script-files](https://github.com/B4lla/script-files)

**Python**

Development utility created to speed up the creation of FiveM resources by automatically generating predefined project structures.
